# ランダムダンジョン生成仕様

## 概要
部屋Prefabをランダムに接続して、毎回異なるダンジョンを生成する。

不思議のダンジョンのように、スタート地点とゴール地点も毎回変化する構成を目指す。

最初は複雑な分岐を作らず、一本道ベースのランダム生成から開始する。

---

# 最小構成

## 方針
- 部屋Prefabをグリッド上に配置する
- StartRoomから順番に部屋を接続する
- 最後に生成した部屋をGoalRoomにする
- 最初は分岐なしの一本道構成にする

---

# 部屋構成

## 使用するPrefab

### StartRoom
開始地点。

### NormalRoom
通常部屋。

### GoalRoom
ゴール部屋。

---

# 部屋接続方式

各部屋は上下左右の入口情報を持つ。

例:
- 上入口あり
- 下入口あり
- 左入口なし
- 右入口あり

部屋同士はDoorPointを接続して配置する。

例:
RoomA の Door_Right
↓
RoomB の Door_Left

---

# 管理方式

## グリッド管理

部屋はグリッド座標で管理する。

例:
- StartRoom : (0,0)
- Room1 : (1,0)
- Room2 : (2,0)
- GoalRoom : (2,1)

同じ座標には部屋を配置しない。

---

# ランダム生成の流れ

1. StartRoomを配置する
2. 現在位置をStartRoomに設定する
3. ランダム方向を選択する
4. NormalRoomを生成する
5. 生成した部屋を現在位置にする
6. 指定回数繰り返す
7. 最後の部屋をGoalRoomに変更する

---

# ゴール不能マップ対策

## 現在の方針
StartRoomから順番に部屋を生成し、最後の部屋をGoalRoomにすることで、必ず到達可能な構成にする。

## 制限
- 最初は分岐なし
- 同じ座標への生成禁止
- 行き止まりになった場合は生成をやり直す
