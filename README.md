# ローグ2D

ステージクリアごとにプレイヤーを強化しながら、ランダムダンジョンを攻略する2Dアクションゲームです。

## ゲーム概要
プレイヤーは重力を切り替える能力と銃を使いながら、ダンジョンを探索します。

ステージをクリアするたびに能力を強化し、より難しいダンジョンへ進んでいきます。

## 現在の操作方法
| 操作 | 内容 |
|---|---|
| WASD | 移動 |
| Space | ジャンプ |
| 矢印キー | 重力変更 |
| Zキー | 銃を撃つ |
| マウス | 能力選択 |
